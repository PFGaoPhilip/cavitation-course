A · Blank model and reference geometry

A · 空白模型与参考几何

Build this in a separate model window from Model A. It is a stationary equilibrium of one PFP inclusion inside a freely deforming gel. The PFP state is represented by global equations; only the gel is meshed. You will not draw a separate vapor sphere or prescribe a cavity displacement.

在与模型 A 分开的新模型窗口中操作。本模型求解一个 PFP 包含物与自由变形凝胶的稳态平衡。PFP 相态由全局方程表示，只对凝胶划分网格；不另画汽核球，也不指定空腔位移。
