All PFP scenarios keep total retained source energy 55 nJ. They use finite liquid/vapor mass and entropy closure, rather than copying the polytropic gas law. cP, c3 and c5 solve each separated source state independently through the shared wave field. cU has a single common source state and is retained only as a rejected physical-closure diagnostic.

所有 PFP 情形总保留源能量均为 55 nJ，使用有限液／汽质量与熵闭合，而不复制多方气体定律。cP、c3、c5 各自求解分离源状态，通过共同波场相互作用；cU 只有一个共同源状态，仅保留为物理闭合被否决的诊断。

02 Add the PFP pressure function: pfpp

添加 PFP 压力函数：pfpp

Right-click Global Definitions → Functions → Analytic. Open pfpp_expression.txt in a text editor, select all its expression text, copy, and paste into Expression. Enter the fields below. Repeat as a new Analytic node for each function.

右击 Global Definitions → Functions → Analytic（解析）。在文本编辑器打开 pfpp_expression.txt，全选表达式、复制、粘贴到 Expression。按下面填写字段；三个函数各自新建一个解析节点。

Field / 字段Select or enter exactly / 精确选择或输入

ExpressionEntire text of pfpp_expression.txt
DerivativesAutomatic
Argument units: TK; rr1; 1
Function unit1

You should see: The Function name is pfpp, not the default an1. Arguments contain a comma and preserve uppercase TK.

应当看到：Function name 是 pfpp，不是默认 an1；Arguments 用逗号分隔，并保留大写 TK。

Why this choice: These are numeric-SI EOS functions. The calling variables divide by input units and multiply by output units explicitly. Only PFP functions are needed; PFH is not the material in these models.

为何这样设置：这些 EOS 函数采用 SI 数值输入输出；调用变量会显式除去输入单位、乘回输出单位。本模型只需 PFP 函数，不使用 PFH。
