COMSOL GUI basics / COMSOL 界面基础

Use this reference whenever a card says “import”, “select” or “generate the solver”. The M1 lesson begins with a complete new-model exercise, so you can learn these operations in context.

步骤卡涉及“导入”“选择”“生成求解器”时，可随时参考此页。M1 从完整新建练习开始，让你在实际操作中学会这些动作。

Load a parameter or variable table / 加载参数或变量表

1. Click the download link, save the TXT file to your practice resource folder, and open it once in a text editor. It contains tab-separated rows without a header. 2. Click the correct Parameters or Variables node in COMSOL. 3. Click Load from File below its table; use the icon’s tooltip if only icons are visible. 4. Select the saved TXT and click Open. 5. Check the first/last names and row count. 6. Save the model. If starting a new component in the same model, append only its new parameter names.

1. 点击下载链接，将 TXT 保存到自己的练习资源目录，用文本编辑器打开一次，确认内容是无表头的制表符分隔行。2. 在 COMSOL 点击正确的 Parameters 或 Variables 节点。3. 点击表格下方 Load from File；只有图标时看悬停提示。4. 选保存的 TXT，点击 Open。5. 检查首尾名称与行数。6. 保存模型。同一模型新增组件时只追加新参数名称。

Never import the heading line “Name Expression” as a parameter. For Global Equations, the four columns are Name, residual, initial value, initial derivative. Enter the visible rows manually if your file dialog does not recognize the four-column format. Expressions contain ASCII operators: * for multiplication, ^ for powers, and parentheses for grouping.

不能把“Name Expression”表头导入为参数。全局方程四列为名称、残差、初值、初始导数；若文件对话框不接受四列格式，按页面表格手动输入。表达式使用 ASCII 运算符：* 乘法、^ 次方、括号分组。

Select the right geometry level / 选择正确几何层级

Level / 层级Meaning / 含义Used here / 本项目用途
Domain / 域A 3D volume / 三维体积Water, receiver, gel, population / 水、接收器、凝胶、泡群
Boundary / 边界A 2D surface bounding a domain / 包围域的二维表面Matching flux, gel cavity load, radiation / 匹配通量、空腔载荷、辐射
Entire model / 整个模型Local component expressions with global scalar availability / 组件表达式及可全局访问的标量Variables such as Vfree and Rfree / 例如 Vfree、Rfree 变量

When a selection field is active, clicking Graphics changes that selection. Click elsewhere before rotating the view. Use named selections from the Selection list, not remembered boundary numbers. For a Box selection, choose Entity inside box explicitly.

选择框激活时，点击 Graphics 会修改选择；旋转视图前先取消选择激活。使用 Selection 下拉框的命名选择，不依赖记忆边界编号。框选择必须明确选 Entity inside box。

Reveal hidden nodes and settings / 显示隐藏节点与设置

To show weak contributions: Model Builder → Show More Options → Equation-Based Contributions. For extra solver/physics fields enable Advanced Study Options and Advanced Physics Options. Right-click Study → Show Default Solver creates Solver Configurations after the equations are entered. Expand triangles until you can see Dependent Variables and Time-Dependent/Stationary Solver.

弱贡献显示：模型开发器 → Show More Options → Equation-Based Contributions。高级求解／物理字段还需 Advanced Study Options、Advanced Physics Options。方程输入完成后右击 Study → Show Default Solver 创建求解器配置。逐层展开直到看到 Dependent Variables 和瞬态／稳态求解器。

Names, labels, units and coordinate case / 名称、标签、单位与坐标大小写

Component Name determines cG.pAc or c.stretch; Label only changes the visible caption. Function name and Operator name must match the expressions, regardless of their tree labels. The bracket syntax 50[um] means a dimensional length; 50 without a unit means 50 in the current context. Uppercase X,Y,Z are material coordinates in the gel; lowercase x,y,z are spatial coordinates. They differ after deformation.

组件 Name 决定 cG.pAc、c.stretch 等前缀；Label 只改变显示标签。Function name 与 Operator name 必须匹配表达式，不能只改标签。50[um] 表示有量纲长度；不带单位的 50 使用当前上下文。凝胶中 X,Y,Z 为材料坐标，x,y,z 为空间坐标；变形后两者不同。

Read errors before changing the physics / 修改物理之前先读错误

Symptom / 现象First check / 首先检查
Unknown variable / 未知变量Spelling, Name, component scope, selected result dataset / 拼写、Name、组件作用域、结果数据集
Empty selection / 空选择Entity level, Inside-box condition, geometric Build All / 层级、框内条件、几何全部构建
Missing material property / 缺少材料属性Active hyperelastic node and User defined property sources / 有效超弹性节点及自定义属性来源
Singular matrix / 奇异矩阵Rigid-motion suppression in B; no unintended zero PDE mass in A / B 刚体运动抑制；A 质量系数没有误设零
Failed to find consistent initial values / 初始一致性失败Phase initial guesses, copied EOS, equation rows / 相态初猜、EOS 文本、方程行
Different peak after “refining” output times / 改输出时间后峰值变化Actual internal step and waveform/energy error, not only stored samples / 真正内部步长、波形／能量误差，不只看存储采样点
