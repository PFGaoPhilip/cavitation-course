Independent native rebuild / 独立原生重建

Use the saved native configuration to check every node, then start in an empty Model Wizard. Parameter/expression files make long EOS entries inspectable; importing expressions is allowed, but the geometry, equations, boundaries, solver and result choices remain your rebuild task.

用保存的原生配置核对每个节点，再从空白模型向导开始。参数／表达式文件便于检查长 EOS 项；可以导入表达式，但几何、方程、边界、求解器和结果选择仍由你重建。

Model A / 模型 A

Node / 节点Exact choice and purpose / 设置与目的
Model Wizard3D → Coefficient Form PDE + Global Equations → Time Dependent. One physics pair per component.
Global DefinitionsUse parameter table, source cards and expression map, plus p(T,ρ), u(T,ρ), g(T,ρ) in pfpp/pfpu/pfpg_expression.txt. Arguments and function results are dimensionless; wrap physical units in variables.
GeometryWater outer sphere Lout=0.9 mm. Single/3/5 components subtract source matching spheres; add a receiver cylinder radius 50 μm, height 5 μm centered at z=0.5 mm. Form Union retains receiver boundaries.
Selections and integrationsSource boxes: entitydim=2, bounds center±1.001b, condition Inside. Receiver: entitydim=3, x/y±1.001a_det, z=r_obs±0.501h_det. Source and receiver integrations must be nonempty. Far boundary is Complement of inside ±0.8Lout boundary box.
Coefficient Form PDEχ=φτ/a². ea=1/c², da=0, c=1, f=0. Initial χ=χ̇=0. Source Flux/Source g=−τQ/(a²A_b), q=0. Radiation g=−χ̇/c, q=1/Lout. No extra spherical radiation term in the radius law.
Global EquationsCopy each dependent-variable/equation/initial-state array from the exact source script. Radius second derivative, phase EOS constraints, dissipated/radiated energy integrators and receiver filter are solved together. Gas uses r, ediss, erout, pdet; each PFP adds θ,qL,qV.
DiscretizationQuadratic Lagrange potential. Global size 150 μm maximum, 5 μm minimum, growth 1.5, curvature .3; resolved source surfaces local maximum a_i/2. The gas geometry uses fixed b=110 μm and the mesh made at case0.
Study activationEach study solves only its own component physics. Global tags use unique component suffixes. Aux gas list 0…6 with source interpolation cards; initialize each from the declared rest state.
SolverFully Coupled + Direct PARDISO. Create the replacement before removing generated Segregated. Manual scales=1, relative tolerance 2e−5, generalized-alpha ρ∞=.75. Baseline 25 ns; authoritative case0 study 6.25 ns internal / 12.5 ns output.
Uniform componentNo holes. Partition a 200 μm population sphere. PDE distributed source = −100τQ/(a²V_pop). One representative phase state coupled to mean population χ̇. Authoritative uniform study uses 6.25 ns internal and relative tolerance 2e−6.
ResultsEvaluate filtered gauge pdet·100 kPa, separate raw receiver mean, R/a, wall Mach, phase and total-energy residuals. Use authoritative studies for gas0 and population. Compare with supplied independent references and numerical controls.

Model B / 模型 B

Node / 节点Exact choice and purpose / 设置与目的
Model Wizard3D → Solid Mechanics + Global Equations → Stationary. Enable geometric nonlinearity.
ParametersFull baseline parameters. a=300 nm radius, B=20, G=10 kPa, K/G=1000, p₀=100 kPa. σ_LL=.054 N/m is an assumed effective PFP/gel coefficient from a water/PFP reference, not a measured gel interface.
Geometry and selectionDifference: sphere radius B·a minus sphere radius a. Cavity boundary Box, Inside, entitydim=2, ±1.001a. All surrounding gel volume retained.
Solid MechanicsHyperelastic Material: Neo-Hookean, Nearly Incompressible, pressure mixed formulation, K/G user-defined; ρ=1006.5 kg/m³. Free outer traction. Rigid Motion Suppression only. No cavity prescribed displacement.
Surface energyFollower Pressure p_l−p₀ on cavity. Boundary Weak Contribution in material quadrature: expanded variation, cofactor/surface variables. Constant σ_LL energy/stress assumption.
Deformed geometry measuresMaterial-frame integration ic on cavity. CN = cof(F)n₀, Js=|CN|. V=−ic[(X+u)CN1+(Y+v)CN2+(Z+w)CN3]/3. R=(3V/4π)^(1/3); A=ic(Js). This measures solved shape without imposing sphericity.
Finite PFP closurep,u,g EOS functions; ρ_l=ρ_lref exp(qL), ρ_v=ρ_vref exp(qV), T=Tref θ. f_v=(V−m/ρ_l)/[m(1/ρ_v−1/ρ_l)]. Solve Laplace, Gibbs equality and retained-energy residual using the literal expression table and full builder.
MeshFree Tetrahedral; quadratic displacements; global hmax=B·a/4, hmin=a/6, growth1.45, curvature.25; cavity local hmax=a/5. Native fine study 77,481 solved DOFs.

Cases0–3, Qdep=13 pJ; global G/σ functions given in GelSensitivityValid3D.java. Restore baseline guesses before baseline recomputation.
Results and acceptanceExport Qdep,R/a,max principal stretch,T,f_v, shell thickness, phase/mass/energy residuals. Check analytic pressure/work and independent mesh changes. The local λ_f=2.1 screen is a proxy, not measured cavity-fracture certification.
