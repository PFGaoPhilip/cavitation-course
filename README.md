# Cavitation course / 空化课程

[Read the course online](https://pfgaophilip.github.io/cavitation-course/)
[在线阅读课程](https://pfgaophilip.github.io/cavitation-course/)

Open **index.html** or **SCHEDULE.html** to read the bilingual course.
打开 **index.html** 或 **SCHEDULE.html** 阅读双语课程。

The course contains 16 generic dynamics chapters, five project-theory chapters, two research appendixes, labeled formula figures, integrated calculations and formula-first reference answers. Historical mini-lessons and review chapters are retained. Every HTML page has a day/night toggle. All fonts, styles and figures are local.
课程包含通用动力学 16 章、项目理论五章、两份研究附录、标注公式图、综合计算和先列公式的参考答案；保留早期微型课程和复习章节。每页均可切换日夜主题，字体、样式和配图均在本地。

Follow G01–G07 → G13 numerical laboratory → G08–G12 → G14–G16 → T01–T05 → Appendixes A and B. Prepared chapters do not establish learner mastery, and the conditional models do not establish experimental project validation.
学习顺序为 G01—G07 → G13 数值实验 → G08—G12 → G14—G16 → T01—T05 → 附录 A、B。备妥章节不代表已掌握，条件模型也不构成项目的实验验证。

Original PDFs and source ZIPs are excluded. Textbook Markdown, code and numerical files linked by the lessons remain available; research-paper links point to original citations. Work logs, learner records, private report attachments and account diagnostics are outside this public export.
此公开版本排除原始 PDF 和源 ZIP。保留课程所链接的教材 Markdown、代码及数值文件，研究论文链接指向原始引文；工作日志、学习记录、私人报告附件和账号诊断不进入公开版本。

For GitHub Pages, publish the root of the main branch. The index.html entry and .nojekyll file are included. To forward the course offline, keep the complete resource folder together.
GitHub Pages 从 main 分支的根目录发布，已包含 index.html 入口和 .nojekyll 文件。离线转发时请保留完整资源目录。

KaTeX 的原 MIT 许可证位于 assets/vendor/katex/LICENSE。科学来源及核查限制列于章节和文献地图。
